REST API Reference & Endpoints

Direct interface to TransitAssist Spring Boot 3.3.5 backend controllers. All business validation rules are strictly enforced in the service layer.

Open Interactive Swagger UI View OpenAPI JSON
CORE CONTROLLER

Assistance Requests API

/api/assistance-requests — Full lifecycle dispatch and scheduling

POST /api/assistance-requests Create assistance request (201 Created)
GET /api/assistance-requests[?status=&userId=&date=] List requests with optional filters
GET /api/assistance-requests/{id} Fetch single request details
PUT /api/assistance-requests/{id} Partial update of route/time (only before completion)
POST /api/assistance-requests/{id}/assign/{helperId} Assign helper — enforces 60m overlap check (409 Conflict)
POST /api/assistance-requests/{id}/complete Mark trip as COMPLETED (requires assigned helper)
POST /api/assistance-requests/{id}/cancel Cancel request (rejected if already COMPLETED)
STAFF DISPATCH

Helpers & Workload API

/api/helpers — Helper roster and daily schedule

POST /api/helpers Register new transit helper
GET /api/helpers List all helpers and certified skills
GET /api/helpers/{id} Get helper profile by ID
DELETE /api/helpers/{id} Soft deactivate helper (204 No Content)
GET /api/helpers/{id}/workload?date=YYYY-MM-DD Get daily workload bookings & summary counts
USER MANAGEMENT

Campus Users API

/api/users — Student, faculty, and coordinator directory

POST /api/users Create campus user profile (201 Created)
GET /api/users List all registered users and roles
GET /api/users/{id} Get user by ID
DELETE /api/users/{id} Deactivate user account (204 No Content)
